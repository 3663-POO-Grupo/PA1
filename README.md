# Programacion Orientada a Objetos PA1
## Sistema basico de registro y control de productos en consola

# Descripcion del Proyecto
Para desarrollar la solución se utilizaron los temas trabajados en clase, como clases, objetos, atributos, constructores, métodos que devuelven valores, métodos que no devuelven valores y estructuras de control.
El proyecto se realizo para una microempresa, el programa fue hecho con codigo Java en IntelliJ po lideratec, la aplicaci+on le permite realizar diferentes funciones pero importantes como registrar todos los productos, llenar el stock, conocer cuando productos existentes hay y los que faltan, muestra la cantidad de producto con todos sus datos, usando atributos, constuctores, metodos que devulven valores y no devulven valores, estructuras entre otros. 

## Instrucciones Mínimas 
1. Clonar el repositorio de GitHub.
2. Abrir el proyecto en IntelliJ IDEA.
3. Abrir el archivo SistemaControl.java.
4. Ejecutar el método main.
5. El programa se ejecutará en la consola y mostrará el menú principal.
6. Usar los números para navegar el menú por consola.

## Desiciones del diseño
1. **Clases:** Se usó Producto como dominio y SistemaControl como ejecutora con el método main. 
2. **Encapsulamiento:** Atributos privados gestionados por constructores y métodos específicos. 
3. **Estructuras de Control:** Uso de do-while para el ciclo de vida del menú, switch para navegación y if-else para validaciones lógicas de las ventas.
